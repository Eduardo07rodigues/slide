# 🖼️ Slide

O **Slide** é um projeto desenvolvido para praticar animações e interatividade com **JavaScript**, criando um carrossel de imagens com diferentes formas de navegação e transições suaves. O projeto utiliza fotos de animais como conteúdo para explorar técnicas de manipulação do DOM e efeitos visuais.

---

## ✨ Funcionalidades

- 🐾 Carrossel de imagens de animais.
- ⬅️➡️ Navegação pelos botões de próximo e anterior.
- 🖱️ Navegação por miniaturas/indicadores.
- ✨ Animações suaves durante a troca de imagens.
- 📱 Layout responsivo.
- 🎯 Diferentes formas de interação para navegar entre os slides.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## 📚 O que aprendi

Durante o desenvolvimento deste projeto pude praticar:

- Manipulação do DOM;
- Criação de animações com JavaScript;
- Eventos de clique e interação do usuário;
- Controle de estado da aplicação;
- Adição e remoção dinâmica de classes;
- Transições e animações utilizando CSS;
- Organização de componentes em JavaScript;
- Desenvolvimento de um carrossel de imagens reutilizável.
